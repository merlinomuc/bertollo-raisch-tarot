# Version 1.3.1

- Familiencode wird vor dem Speichern serverseitig geprüft.
- Nach erfolgreicher Prüfung verschwinden Eingabefeld und Speichern-Schaltfläche.
- Eine dauerhafte grüne Bestätigung wird angezeigt.
- Anmeldung bleibt über ein sicheres HttpOnly-Cookie 180 Tage erhalten.
- Alter im Local Storage gespeicherter Code wird einmalig in das neue Cookie migriert.
- Schaltfläche „Code ändern“ löscht die gespeicherte Anmeldung.
- Verständliche Meldungen für falschen Code, Netzwerkfehler, HTTP-Fehler und unerwartete Browserfehler.
- PWA-Cache auf Version 1.3.1 erhöht.
