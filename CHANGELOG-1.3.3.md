# Version 1.3.3

- Mikrofon-Button neben allen geeigneten Texteingaben ergänzt.
- Deutsche Spracheingabe über die Web Speech API (`de-DE`).
- Laufende Aufnahme wird am Button sichtbar angezeigt und kann beendet werden.
- Erkannter Text wird in das jeweilige Feld übernommen und löst die vorhandenen Eingabe-Handler aus.
- Verständliche Hinweise bei fehlender Browser-Unterstützung, verweigertem Mikrofonzugriff, fehlendem Mikrofon oder Erkennungsfehlern.
- Passwort- und Zahlenfelder bleiben bewusst ohne Spracheingabe.
- PWA-Cache auf Version 1.3.3 angehoben.
