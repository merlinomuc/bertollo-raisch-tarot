# Version 1.3.2

- Kürzere, strukturierte Tarotdeutungen.
- Thema der Legung wird zu Beginn knapp wiederholt.
- Jede Karte wird positionsgetreu in einer eigenen Karte dargestellt.
- Feste Abschnitte: Zusammenfassung, Gesamtanalyse, Einschätzung, Kernaussage, Essenz und Reflexionsfrage.
- Vorgeschlagene Folgefrage kann direkt ausgewertet werden.
- Alternativ kann eine eigene Folgefrage eingegeben werden.
- Folgefragen vertiefen dieselbe Legung; es werden nicht automatisch neue Karten gezogen.
- Modellantwort wird als strukturierte JSON-Antwort verarbeitet und sicher als HTML dargestellt.
